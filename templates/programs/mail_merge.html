Program Mail Merge

A mail merge sends each student their own copy of one email, with their details filled in. For example, "Hi {% templatetag openvariable %} first_name {% templatetag closevariable %}, you have {% templatetag openvariable %} attendance_total_hours {% templatetag closevariable %} hours" becomes "Hi Sam, you have 42.5 hours" in Sam's email and "Hi Alex, you have 38.0 hours" in Alex's.

How it works
  1. Choose students: pick a program, and a team, crew or subteam if you want to narrow it down, then load the list.
  2. Check the table: each row is one student and each column is a piece of information about them. Untick anyone who shouldn't get the email. To include information the portal doesn't have, such as a due date or a note, add your own column and type or paste it in.
  3. Write the email: use the Insert field menus to add placeholders such as {% templatetag openvariable %} first_name {% templatetag closevariable %}. Each placeholder is replaced with that student's value from the table.
  4. Preview and test: step through students to see exactly what each will receive, and send yourself a test copy.
  5. Send: review the count, then confirm. Everyone gets a separate email, so no one sees anyone else's address or information.

Nothing on this page is saved as a draft. If you leave or reload the page, the email and any information you typed or pasted are lost.
